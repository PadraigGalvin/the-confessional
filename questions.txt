# One question per line. Blank lines and lines starting with # are ignored.
# {birthday} is replaced with "birthdayName" from config.json.
# This file is re-read for every new session, so you can edit it while the booth is running.
#
# Each line has the question in French, then | and the question in English, in the order of
# "languages" in config.json. Guests pick their language on the start screen, and only get
# questions in that language. A line with no | is only asked in French; start a line with |
# to ask it only in English. The English doesn't have to be a translation: where a joke or
# a pun doesn't carry over, put a different question that works in English.
#
# Write the French for "tu". Put an ordinary space before ? ! : ; and the booth swaps in
# the right French space. "de {birthday}" and "que {birthday}" become "d'" and "qu'" by
# themselves if the name starts with a vowel.
#
# The [funny], [cute] and [last] lines split the questions into sections.
# "questionMix" in config.json sets how many each guest gets from each section.
# The [funny] and [cute] questions are shuffled together, and the [last] one always comes last.
# When the birthday person is in the booth, questions with {birthday} in them are skipped,
# and the gaps are filled from the other [funny] and [cute] questions.
